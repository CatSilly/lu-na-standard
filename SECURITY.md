# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please do **not** open a public issue.

Instead, contact me at:

- GitHub Security Advisories (preferred): https://github.com/CatSilly/Lu-Na-standard/security/advisories

Please include:

- Description
- Steps to reproduce
- Expected and actual behavior
- Proof of concept (if available)

I will acknowledge reports within a few weeks and work on a fix as soon as possible.

Thank you for helping improve the security of this project.
